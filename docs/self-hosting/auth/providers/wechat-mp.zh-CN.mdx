# 配置微信服务号身份验证

[微信公众平台](https://mp.weixin.qq.com/) 支持 OAuth 2.0 网页授权，允许第三方网站实现微信登录。与微信开放平台不同，服务号不需要通过网站应用审核——只需要一个已认证的服务号即可。

<Callout type={'warning'}>
  微信服务号 OAuth 需要**已认证的服务号**（认证服务号）。未认证的订阅号无法使用 OAuth 接口。
</Callout>

<Steps>
  ### 获取服务号凭证

  1. 前往 [微信公众平台](https://mp.weixin.qq.com/)
  2. 注册或登录你的已认证服务号
  3. 进入 **设置与开发** > **基本配置**
  4. 记录 **AppID** 和 **AppSecret**

  ### 配置网页授权域名

  1. 在 **基本配置** 中找到 **网页授权域名**
  2. 点击 **设置**，输入你的回调域名（不含协议和路径）：

  <Callout type={'info'}>
    回调域名格式：

    - **回调域名**：`your-domain.com`（不含协议和路径）
    - **完整回调 URL**：`https://your-domain.com/api/auth/callback/wechat-mp`
  </Callout>

  3. 下载验证文件并放置于域名根目录，或通过反向代理配置

  ### 配置环境变量

  | 环境变量                        | 类型 | 描述                              |
  | --------------------------- | -- | ------------------------------- |
  | `AUTH_SECRET`               | 必选 | 会话加密密钥，使用 `openssl rand -base64 32` 生成 |
  | `AUTH_SSO_PROVIDERS`        | 必选 | 填写 `wechat-mp`                  |
  | `AUTH_WECHAT_MP_APP_ID`     | 必选 | 微信服务号的 AppID                    |
  | `AUTH_WECHAT_MP_SECRET`     | 必选 | 微信服务号的 AppSecret                |

  <Callout type={'tip'}>
    前往 [📘 环境变量](/zh/docs/self-hosting/environment-variables/auth#微信服务号)
    查看详细信息。
  </Callout>
</Steps>

<Callout type={'info'}>
  部署成功后，用户将可以通过微信服务号认证并使用 LobeHub。
</Callout>

## 工作原理

登录流程：

1. 用户在 LobeHub 登录页点击「微信服务号」
2. LobeHub 将用户重定向到 `https://open.weixin.qq.com/connect/oauth2/authorize`
3. 浏览器显示一个二维码（由授权 URL 编码生成）
4. 用户使用微信手机端扫描二维码
5. 微信在应用内浏览器打开授权页面
6. 用户确认授权（拉取其微信头像和昵称）
7. 微信将用户重定向回 LobeHub，并携带授权码
8. LobeHub 用授权码换取 access token，获取用户信息

## 注意事项

- 需要**已认证的服务号**，不需要开放平台账号
- 使用 `snsapi_userinfo` 授权 scope —— 可拉取用户昵称、头像和 OpenID
- 用户需关注该服务号才能授权（`snsapi_userinfo` 要求关注）
- 若在国内服务器部署，回调域名需进行 ICP 备案

## 与微信开放平台对比

|                     | 服务号 (wechat-mp)                     | 开放平台 (wechat)                        |
| ------------------- | ------------------------------------- | --------------------------------------- |
| 账号类型               | 已认证服务号                              | 已认证开放平台                              |
| 网站应用审核             | 不需要                                  | 需要                                     |
| 授权 URL             | `/connect/oauth2/authorize`           | `/connect/qrconnect`                    |
| Scope               | `snsapi_userinfo`                     | `snsapi_login`                          |
| 关注要求               | 需要（`snsapi_userinfo` 要求）            | 不需要                                    |
| Token / Userinfo API| 相同                                    | 相同                                     |
